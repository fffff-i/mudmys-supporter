# 幕間ノート

マーダーミステリーのシナリオ資料をまとめ、現在の状況、根拠付きの出来事、優先して確認する行動を整理するWindowsデスクトップアプリです。シナリオごとに資料と方針履歴を分けて保存します。

## 主な機能

- シナリオ概要、テキスト、PDF、画像を保存。テキストの貼り付けと複数ファイルの追加に対応します。
- 現在の状況、時刻・人物・出来事の索引、事実・仮説・未確認事項を表示します。
- 次に誰へ何を確認するかを優先順に提案し、理由と資料の根拠を確認できます。
- 自分の役・目的・秘密を任意に登録し、解析へ含めるか選べます。
- 方針を棄却・完了・置き換えた理由を履歴に残します。棄却した案は自動で再提案されません。
- シナリオごとのデータをローカルに保存し、バックアップを書き出せます。

## 開発環境

Node.js 22.13以降とnpmが必要です（Viteは20.19以降または22.12以降、PDF.jsが22.13以降を要求します）。

```powershell
npm install
npm run dev
```

確認には次を実行します。

```powershell
npm test
npm run build
```

Windows向けportable版を生成するには `npm run package:portable` を実行します。生成物は `release-v0.2.1/` に出力されます。このフォルダーは公開リポジトリには含めません。

## AI接続

AIは初期状態では未接続です。未接続でも資料の保存、整理、シナリオごとのバックアップを利用できます。設定から次の接続先を選べます。

- **OpenAI API:** APIキーをWindowsの暗号化ストレージに保存し、同意した資料をAPIへ送信します。ChatGPT/Codexの契約とは別のAPI利用料がかかる場合があります。
- **Ollama:** このPCのlocalhost上のOllamaへ接続します。画像の読解可否は選んだモデルによって異なります。PDFページ画像は送信せず、抽出できたテキストを使います。
- **Codex（ChatGPTの契約枠）:** 公式Codex CLIのApp Serverを使う実験的な接続です。設定画面から専用profileへのChatGPTサインインを開始し、表示されたデバイスコードを利用者自身が公式認証ページで入力します。アプリはブラウザーを開かず、通常のCodex認証情報をコピーしません。Platform APIへフォールバックしません。

OpenAI APIとCodexでは、シナリオ概要、資料全文、画像、PDF、現在の方針状態を選択した接続先へ送信します。役・目的・秘密は、設定で「自分の役・目的・秘密を解析に含める」を有効にした場合だけ送信します。利用前に設定画面の送信範囲を確認してください。自動更新は個別の同意が必要です。

Codexでは利用可能モデルをCLIから取得し、選択したモデルに切り替えます。モデルが利用できない場合に別のモデルやAPIへ自動変更しません。対応CLIが必要で、App Server仕様は変更される可能性があります。shell、apps、remote plugins、multi-agent、web searchを設定で無効にし、read-only sandboxとネットワーク制限を指定します。予期しないツールや権限要求では解析を中断します。ただし、App Serverの読み取り範囲を個別指定できず、内部機能すべての無効化も保証できないため、完全に隔離された実行環境ではありません。

## 資料と保存

原文と添付ファイルは要約で置き換えずローカルに保持します。テキスト/PDFから得た引用は照合し、画像から読み取った引用は未検証として表示します。AIの要約・引用・人物解釈は誤る可能性があるため、判断時は原資料を確認してください。

1ファイル20 MiB超は取り込み前に拒否し、保存しません。取り込み済み資料の解析対象が合計40 MiBまたは抽出テキスト30万文字を超える場合、解析を止めて原本を保持します。CodexではさらにPDF合計200ページと生成画像合計40 MiBを、このアプリ側の安全上限として設定しています。いずれもCodexの公式上限を示す値ではありません。超過時にページや文章を黙って切り捨てません。

シナリオはアプリのユーザーデータ領域へローカル保存されます。シナリオバックアップにはAPIキーやCodex専用profileを含めません。
